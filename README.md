### This is Elle Adams MADA project repository

# Overview
Data analysis project/paper done with R/Quarto/GitHub by Elle Adams for MADA course Spring 2026. 

# Pre-requisites
This is the data analysis project of Elle Adams, made using a template for the final project for the UGA MADA course and using R, Quarto, and GitHub. Recommended, but not strictly required, is a reference manager that can handle BibTeX (ex - Zotero). 

# Structure and content
* All code goes into the `code` folder and subfolders. Currently, there are 3 sub-folders that do different parts of an analysis, analysis-code, exploratory-code, and processing-code. 

* All data goes into the `data` folder and subfolders. Currently, there are 2 sub-folders that contain different versions of a the BEAM dataset, raw-data and processed-data.

* The `products` folder and its subfolders contain all _deliverables_, such as the manuscript. 
  - The  `manuscript` subfolder contains a .qmd file written to generate the manuscript, and the .docx rendered version of this. 
  -Within the manuscript subfolder is subfolder supplement, containing .qmd and .pdf versions of supplementary data referenced in the manuscript.
  -Another subfolder wihtin manuscripts is assets, which contains bibtex format references for the manuscript. 
  
* The `results` folder contains all automatically/code generated output. For this study, the this output was primarily figures.  

* There are multiple special files in the repo.
  * `readme.md`: this file contains instructions or details about the folder it
  is located in. You are reading the project-level `readme.md` file right now. There is a `readme` in almost every folder.
